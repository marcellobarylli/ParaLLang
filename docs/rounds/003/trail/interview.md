# Interview: round 003

Opening request (Owner): "next feature is to change the default language to italian"

The three questions were asked together in one prompt; the answer time was not captured.

### Q1 (unknown): Should Italian replace Spanish, or should the target language become configurable with Italian as the default?
- **Options offered:** "Configurable, Italian default (Recommended)": add a target-language setting (e.g. TARGET_LANGUAGE=it in .env); content, prompts, voice and UI labels come from the language pack; Spanish stays as a working option. "Replace Spanish": convert the game to Italian and delete the Spanish content.
- **Answer:** Configurable, Italian default (Recommended)

### Q2 (unknown): Gerald's encounter is about ordering black coffee. In Italy 'un caffè' already means an espresso. How should the Italian version be written?
- **Options offered:** "Idiomatic Italian (Recommended)": un caffè, vorrei, senza latte, caffè macchiato / caffellatte as the milk trap, written with dictionary sources (Treccani, Cambridge Italian–English) for owner review. "Literal translation": caffè nero, voglio, senza latte.
- **Answer:** Idiomatic Italian (Recommended)

### Q3 (unknown): What should happen to Spellbook cards that already hold Spanish words?
- **Options offered:** "One Spellbook per language (Recommended)": each language has its own Spellbook; Spanish progress is kept. "Start fresh": ignore or clear the old Spanish saves.
- **Answer:** One Spellbook per language (Recommended)
