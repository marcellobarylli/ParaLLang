# Round 113 architecture

**Conversational round, logged after the build.** Built on 2026-11-14 with the owner, not through the round pipeline,
and recorded after the work was done, so no section is marked pre-run. The full record (interview, timeline) is in
`trail/`; it is not needed to implement this round.

- **Design source:** the owner's request and a screenshot (a greentext about an NPC who gives the player an item,
  vanishes, and returns ten hours later, dying). Neither the character nor Micromort Mountain is in
  `parallang_obsidian/`; both are new.
- **Findings:** [`findings.md`](findings.md).
- **Interview:** [`trail/interview.md`](trail/interview.md).
- **Timeline:** [`trail/journal.md`](trail/journal.md).

## Goal

1. A character, Bambieshart from Zanzibart, playable in a full encounter in both packs.
2. A mention of Micromort Mountain as a place to visit.

## Owner decisions

Offered and chosen are in [`trail/interview.md`](trail/interview.md): a full encounter (Q1) and the mountain as a
lore teaser, no map node of its own (Q2).

## Design

- **Character** `wanderer_bambieshart_001` (`content/characters/enemies/wanderer_bambieshart.yaml`). Speech in a
  half-invented archaic English from the screenshot ("althoughbeitfully the mimsy broves outgrathe"); calls the
  player the Tarnished; presses Bambieshart's Brocade into their hands; says he left Zanzibart to the Glimmer Tugs
  though the promise to the Old Nanny was never removed from the High Gate. `saveable: false` (a saveable character
  needs a party conversation; none was asked for).
- **Location** `the_high_gate` at (0.9, 0.36), connected to The Cracked Fountain. Its description holds the teaser:
  a signpost reading MICROMORT MOUNTAIN, 14 KM, ONE CHANCE IN A MILLION PER STEP, with a pencilled note, "that is a
  lot of steps". The sign is the owner's mountain; one micromort is a one-in-a-million chance of death. The
  description and the character are shared by both packs.
- **Encounter** `high_gate_bambieshart`, per pack. Objective 1: thank him (reuses Gerald's `grazie`/`gracias`).
  Objective 2: ask about the mountain (new word `montagna`/`montaña`, file `bambieshart_gate`). A first draft added
  "where" (`dove`/`dónde`) but the word already appears in existing lore, so the answer-leak tests failed; it was
  dropped.
- **Optional place.** The High Gate is outside the Rift's gate (still five encounters), the tour order and Errata's
  vocabulary review. Making it required would also need Errata to review `montagna`.
- **App.** A wind-and-bell ambience loop for the new location, generated by `mobile/scripts/gen-ambient.js`.

## Tests

Existing tests that hard-coded the location and encounter lists now include the new location (`world`, `atmosphere`,
`encounters`, `language-engine`) or exclude it where it is optional (`rift-gate`, `rift-boss`, `play-market`); the
ambience test counts seven. No new test file.
