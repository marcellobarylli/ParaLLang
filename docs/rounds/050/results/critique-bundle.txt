===== docs/rounds/050/trail/plan-v1.md
     1	# Round 050 plan v1: telling the time at the Cracked Fountain (backlog G5)
     2	
     3	Autonomous round (no owner present). Round 011 built Flick the Letharger at the Fountain with three ordered
     4	objectives (stop, direction, now) and deferred "telling the time" (prototype.md §8.2 gives the Fountain "time,
     5	directions, commands"; round 011 architecture: "No telling the time (numbers would need their own objective)").
     6	
     7	## Goal
     8	
     9	The player tells Flick the time, in the target language, as a fourth objective of the Fountain encounter, in both
    10	packs, with live runs that show the grader accepts a time and rejects non-times.
    11	
    12	## Design
    13	
    14	1. **Objective `time`**, inserted between `direction` and `now` (ordered encounter, `now` stays last because its
    15	   intent carries the jingle, which must reach every narration line: round 025 trap). `direction.next_objective`
    16	   becomes `time`, `time.next_objective` is `now`.
    17	   - Prompt: "Flick swears it is far too early to do anything. Tell it what time it is, in Italian." (es: Spanish)
    18	   - Intent: "The fountain's clock stopped long ago and Flick says it is always too early. The player tells Flick
    19	     the time, any hour, in Italian (it is one o'clock, it is three, midday, midnight). Flick may ask what time it
    20	     is, but never says a time itself."
    21	   - Passes: any hour stated as the player's own statement of the time, minutes optional. Fails: "now" alone
    22	     (adesso / ahora: that is the next objective), a question back ("Che ore sono?"), English, "later/tomorrow".
    23	2. **Vocabulary** (added to `fountain_riddles.yaml`, version `-v2`, no new file so the Rift's chip coverage and the
    24	   aggregate stay one file per encounter):
    25	   - it targets: `sono_le` phrase *sono le* ("it is … o'clock", plural hours), `luna` phrase *l'una* (surfaces
    26	     *è l'una*, *l'una*), `mezzogiorno` (midday, noon), `mezzanotte` (midnight).
    27	   - it non-target (chips for Flick's question): `che_ore_sono` phrase *che ore sono* (also *che ora è*).
    28	   - es targets: `son_las` phrase *son las*, `la_una` phrase *la una* (surfaces *es la una*, *la una*), `mediodia`
    29	     (*mediodía*), `medianoche`.
    30	   - es non-target: `que_hora_es` phrase *qué hora es*.
    31	   - Required group: all four targets (one of them must be matched as evidence; any hour then follows them).
    32	3. **No number vocabulary.** Hour numbers are not authored: English collisions (it *due*, es *once*), twelve
    33	   entries per pack, and the Rift would review them. The grader accepts any hour; the midday/midnight path needs no
    34	   number. The hint path reveals *sono le* / *son las*. Open item for the owner: a numbers lesson.
    35	4. **Flick's character file is unchanged** (shared with its party conversations, which would change otherwise);
    36	   the encounter's `defeat_condition.description` names the time.
    37	5. **Tests:** `fountain.test.js` scripts become 8 answers (adds a now-only answer that fails `time` and a variant
    38	   time that passes); the verdict table grows by `time`. `encounters.test.js` / `language-engine.test.js` pins move
    39	   to `fountain-riddles-*-v2`. Lore-fragment, containment, party-overlap and stem tests must pass unchanged (a
    40	   fragment holding a new form is rewritten, not the test).
    41	6. **play-market.js** `cracked_fountain` script: it `['Guarda!', 'Fermati!', 'Left.', 'A sinistra!', 'Adesso!',
    42	   "È l'una, Flick.", 'Domani.', 'No, adesso!']`; es `['¡Mira!', '¡Quieto!', 'Left.', '¡A la izquierda!',
    43	   '¡Ahora!', 'Es la una, Flick.', 'Mañana.', '¡No, ahora!']`. The Rift's scripts are unchanged.
    44	
    45	## Live runs (codex-cli)
    46	
    47	- 2 × it and 2 × es `--location cracked_fountain` (~17 calls each). Run 2 of each language uses `--lines` with a
    48	  question back (*Che ore sono?* / *¿Qué hora es?*, should fail) and the plural form (*Sono le tre.* / *Son las
    49	  tres.*) or midday (*È mezzogiorno!* / *¡Es mediodía!*).
    50	- Then one `--tour` (it) if Codex has budget, as the end-to-end regression.
    51	- Measure: verdicts vs scripted, Flick saying a time itself (a leak of the open objective), the language share of
    52	  Flick's lines (round 011: near the requested share), the jingle still present, and `leak-scan.js` on every report.
    53	
    54	## Success
    55	
    56	All server, mobile and client tests pass; every live verdict matches the script, or a mismatch is explained; Flick
    57	does not state the time in ≥ 3 of 4 runs.

===== server/src/language-engine.js (matchCanonicalVocabulary)
     1	export function matchCanonicalVocabulary(text, vocabulary) {
     2	  const source = String(text ?? '');
     3	  const folded = source.normalize('NFD').replace(/\p{M}/gu, '').toLowerCase();
     4	  const entries = [...vocabulary].sort((a, b) => {
     5	    const longestA = Math.max(...a.surface_variants.map((form) => form.length));
     6	    const longestB = Math.max(...b.surface_variants.map((form) => form.length));
     7	    return longestB - longestA;
     8	  });
     9	  const occupied = [];
    10	  const matches = [];
    11	  for (const entry of entries) {
    12	    const variants = [...entry.surface_variants].sort((a, b) => b.length - a.length);
    13	    for (const variant of variants) {
    14	      const form = variant.normalize('NFD').replace(/\p{M}/gu, '').toLowerCase();
    15	      const pattern = escapeRegExp(form).replace(/\s+/g, '\\s+');
    16	      const expression = new RegExp(`(?<![\\p{L}\\p{N}_])${pattern}(?![\\p{L}\\p{N}_])`, 'gu');
    17	      for (const result of folded.matchAll(expression)) {
    18	        const start = result.index;
    19	        const end = start + result[0].length;
    20	        if (occupied.some(([usedStart, usedEnd]) => start < usedEnd && end > usedStart)) continue;
    21	        occupied.push([start, end]);
    22	        matches.push({ id: entry.id, entry, excerpt: source.slice(start, end), start, end });
    23	      }
    24	    }
    25	  }
    26	  return matches.sort((a, b) => a.start - b.start);
    27	}
